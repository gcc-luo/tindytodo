# 工作时间提醒与下班庆祝设计规格

## 目标

为 TinyTodo 增加工作节奏提醒：用户可以分别设置午休和下班时间、启用状态与重复方式。主界面明显展示下一次提醒的倒计时；到达下班时间后，在当前显示器上打开一个覆盖其他窗口的全屏庆祝窗口，点击任意位置退出。

## 范围

- 支持午休提醒和下班提醒两类提醒。
- 每类提醒独立启用或关闭。
- 每类提醒支持“每天重复”或“一次性”。
- 一次性提醒包含日期与时间；触发后自动标记为已完成并关闭启用状态。
- 每天重复提醒按本机时区计算下一次触发时间。
- 倒计时显示在主窗口顶部状态区域，按秒刷新。
- 下班庆祝覆盖当前显示器；不覆盖其他显示器。
- 庆祝窗口置顶、无边框、全屏显示，点击任意位置关闭。
- 保留浏览器开发模式的 localStorage 回退；Tauri 桌面模式使用现有 SQLite `app_meta` 表。

不包含系统通知中心推送、电脑锁定、阻止 Alt+Tab、跨显示器同步或应用完全退出后的系统级唤醒。

## 数据模型

新增前端类型 `WorkReminderSettings`：

- `enabled`: boolean
- `time`: `HH:mm`
- `repeat`: `'daily' | 'once'`
- `date`: `YYYY-MM-DD | null`，每天重复时为空
- `completed`: boolean，仅一次性提醒使用

新增 `WorkSettings`：

- `lunch`: `WorkReminderSettings`
- `offWork`: `WorkReminderSettings`

SQLite 使用 `app_meta` 保存 JSON 配置，键名为 `work_reminders_v1`。读取时对缺失或损坏数据使用安全默认值；保存时覆盖同一个键，不引入新的数据库表或迁移版本。

## 界面

### 顶部倒计时条

在主窗口现有顶部栏下方增加状态条，仅当至少有一个有效提醒时显示：

- 下班前优先显示“距离下班 HH:MM:SS”。
- 午休前且早于下班提醒时显示“距离午休 HH:MM:SS”。
- 午休期间显示“午休中”。
- 没有可用提醒时隐藏。

状态条使用当前项目的浅绿色视觉语言，保持明显但不遮挡任务内容。

### 设置弹窗

在现有“设置”弹窗中增加“工作节奏”区域。午休与下班各自包含：

1. 启用开关
2. 时间输入
3. 重复方式选择：每天重复 / 一次性
4. 一次性模式下显示日期输入

切换到每天重复时清空日期；关闭提醒时保留时间和重复方式，方便下次重新启用。保存失败显示现有 toast 错误，不关闭弹窗。

### 全屏庆祝窗口

新增独立 Tauri 窗口 `celebration`：

- 无边框、透明装饰关闭、置顶、全屏。
- 创建或显示时定位到主窗口当前所在的显示器。
- 下班使用“下班啦，今天也辛苦了”文案和绿色至暖黄色渐变。
- 午休使用较轻的“午休时间到了”文案和同一视觉语言。
- 使用 CSS 彩纸粒子动画，不依赖网络资源。
- 点击任意位置通知主窗口关闭庆祝窗口并恢复焦点。
- 用户按 `Esc` 时也允许关闭，避免窗口无法退出。

## 数据流

1. 应用启动时加载工作设置。
2. Vue 每秒读取当前本机时间，计算两类提醒的下一次触发时间。
3. 当当前时间首次跨过目标时间，记录本地触发标识，避免同一分钟内重复触发。
4. 下班触发时调用 Tauri 命令显示庆祝窗口；浏览器模式显示模拟全屏遮罩。
5. 一次性提醒触发后保存 `completed: true` 与 `enabled: false`。
6. 每天重复提醒在下一个本地日重新计算，不修改配置。
7. 设置修改后立即保存并刷新倒计时。

## 时间与边界处理

- 所有时间比较使用本机时区和本机当前日期。
- 应用从休眠恢复或系统时间被调整时，下一次 tick 重新计算，不补发已经错过的提醒。
- 每个提醒每天最多触发一次。
- 一次性提醒日期早于今天时视为过期，不触发，设置界面显示需要重新选择日期。
- 时间输入缺失或格式无效时不保存，并提示用户。
- 庆祝窗口打开失败时回退为主窗口内的全屏遮罩，并显示错误提示。

## 测试与验证

- 为倒计时计算、每天重复、一次性完成、跨午夜和过期日期添加 Vitest 单元测试。
- 为设置保存和读取添加 API 层测试，覆盖 native 与 localStorage 回退。
- 手动验证设置弹窗的字段联动、顶部状态条的秒级刷新、点击关闭庆祝和 Esc 关闭。
- 运行 `pnpm test`。
- 运行 `pnpm build` 与 `pnpm tauri build --no-bundle` 验证类型、前端构建和 Tauri 配置。

## 验收标准

1. 用户能分别配置午休与下班提醒，并选择每天重复或一次性。
2. 主界面明显显示最近提醒的倒计时。
3. 下班时间到达时，当前显示器出现覆盖其他窗口的全屏庆祝。
4. 点击任意位置或按 Esc 能退出庆祝并回到 TinyTodo。
5. 一次性提醒只触发一次，重启应用后设置仍然存在。
6. 现有任务、清单、快捷键和更新功能不受影响。
