# TinyTodo 日记功能实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `executing-plans` 逐任务实现此计划。步骤使用复选框跟踪进度。

**目标：** 在 TinyTodo 中增加本地优先的多篇/日富文本日记工作区，支持日历、标签、搜索、图片和回收站。

**架构：** Rust/SQLite 提供日记、标签、回收站和图片元数据；Vue 通过统一 API 调用 Tauri 命令，浏览器模式使用 localStorage 与 IndexedDB。独立的日记工作区和 Tiptap 编辑器与现有任务页面分开，图片文件保存到应用数据目录并通过受限的 asset protocol 显示。

**技术栈：** Vue 3、TypeScript、Tauri 2、Rust、SQLite、Vitest、Tiptap Vue 3、Tauri Dialog 插件。
